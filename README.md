# PlayTrade - Aplicações Web 2026/2027

**Descrição**
Website destinado à troca de videojogos físicos para consolas PlayStation. A plataforma foca-se na economia circular e cria um ponto de encontro seguro para a comunidade renovar as suas bibliotecas de jogos através de trocas diretas, sem transações monetárias.
